TROUBLESHOOTING
===============

If deployment fails:
1. Check GitHub Actions tab for error logs
2. Verify .github/workflows/deploy.yml syntax
3. Ensure all relative paths are correct in HTML/CSS/JS
4. Check that index.html exists in repository root
5. Verify GitHub Pages is enabled in Settings

If game doesn't load:
1. Check browser console for JavaScript errors (F12)
2. Verify all assets are loading (Network tab)
3. Check file paths match exactly (case-sensitive on Linux)
4. Clear browser cache (Ctrl+Shift+Del)
5. Try incognito/private browsing mode

If controls don't work:
1. Check that game.js is loaded in browser console
2. Verify keyboard event listeners are attached
3. Test with both keyboard and buttons
4. Check for JavaScript errors in console
5. Verify gameCanvas element exists in HTML
